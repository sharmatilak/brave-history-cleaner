Brave History Cleaner

Add domains whose browsing history should be removed automatically. Only history entries are deleted. Cookies, cache, storage, passwords, bookmarks, and downloads are not modified.

History for these sites is removed automatically when a tab closes, every minute in the background, and fully on browser startup. Use the popup button for an on-demand full sweep.

Import / Export

Export your list to a .txt file (one domain per line), or import one. Lines are normalized (lowercased, stripped of https://, www., paths, and ports) and duplicates are removed.
